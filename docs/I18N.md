# Internationalization (i18n) Guide

Desert Gold supports three languages from day one:
1. **Arabic (`ar`)** — Primary, Right-to-Left (RTL)
2. **French (`fr`)** — Secondary, Left-to-Right (LTR)
3. **English (`en`)** — Secondary, Left-to-Right (LTR)

## Adding a Translation String
1. Open `src/locales/ar.json`, `src/locales/fr.json`, and `src/locales/en.json`.
2. Add your key under the appropriate namespace with identical structure in all three files.
3. Run `npm run i18n:check` to verify key parity across all dictionaries.

## Using Translations in Components
Use the server/client-safe `t(key, locale)` helper:
```tsx
import { t } from '@/lib/i18n/t';

// inside component:
{t('common.brand', locale)}
```

## i18n Drift Guard
Our CI pipeline and local checks run `npm run i18n:check` (`scripts/check-i18n.mjs`), which automatically fails the build if `ar.json`, `fr.json`, or `en.json` have mismatched key sets.
